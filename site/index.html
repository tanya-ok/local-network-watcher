What the Mac can show

The diagram makes observations easier to understand; it does not create visibility the operating system does not provide.

ViewEvidenceBoundary
ConnectionsOpen socket endpoints and owning process when macOS exposes them.Short-lived connections may disappear between snapshots; protected processes may be hidden.
Process trafficAggregate byte and packet counters from macOS, with a rate estimated between snapshots.Totals are not assigned to individual sockets.
Flight MapLocal process, socket, route lookup and next-hop gateway.Internet routers and the far-end socket are outside this Mac's view.
TShark captureSelected decoded headers and protocol fields during a short capture.Not a full protocol-tree interface; TLS application contents are not decrypted.

Investigation cues are not verdicts. A new destination, unfamiliar process, or unusual port can be worth checking. None alone proves malicious activity.

Run locally

The monitor is built for macOS. Rust reads system network observations; Node.js serves the local interface.

cargo build   then   npm start

Open http://127.0.0.1:4317. The server listens on loopback. See the repository README for optional TShark, local Ollama explanations, data retention and platform limitations.
